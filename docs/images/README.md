# Screenshots

Pasta preparada para screenshots públicos do OrbLink.

Use somente dados sintéticos. Não incluir nome do computador/usuário, IP pessoal, caminhos, histórico real, arquivos pessoais, tokens, clipboard ou notificações do Windows. Antes de adicionar imagens, abra e revise cada captura. Não copie automaticamente todos os previews de `outputs/`.
